# Pedro's Sandbox

Quick experiments and new game ideas start here. When an idea becomes a real game, give it its own repo named `pedro-<game>`.

## How to start a new Claude Code session
1. Open claude.ai/code → New session.
2. In **Repo**, pick `pedro-sandbox` (or the game's `pedro-...` repo). Never pick beija, money, Arborium, Salsa or Gymgosh — those are Dad's.
3. Describe the game.
